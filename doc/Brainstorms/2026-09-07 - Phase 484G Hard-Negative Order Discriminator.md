# Phase 484G hard-negative order discriminator

Date: 2026-09-07

Status: development only; no lock, holdout, or FAED

Phase 484F showed that maximising the scalar spectral distance selects false
local maxima even when the planted order is globally unusual. This probe asks
a narrower question: can a fixed, board-substitution-invariant feature vector
distinguish planted orders from the exact false maxima produced by that
search?

Training and evaluation use disjoint fixtures from the development corpus.
Each fixture contributes one planted order, valid random orders, and false
maxima generated by annealing from independent random starts. Features include
the five spectral-component residual summaries, segmentation/concentration
statistics, lagged equality rates, and the local swap-neighbourhood curvature.
No decoded letters or planted-order distance enters the features.

The classifier is a deterministic diagonal nearest-centroid discriminant. It
is intentionally simpler than the candidate generator and has no tuned
hyperparameters. Evaluation ranks the planted order against fresh random and
hard-negative orders for every width/board-mode cell.

Three fixed ablations separate the first 40 cheap features from the nine
swap-neighborhood features, and isolate the 20 segmentation/transition/lag
features. This determines whether a successful discriminator is computationally
usable inside a later search rather than merely descriptive after the fact.

Development promotion criterion: the planted order must rank first in at least
80% of evaluation fixtures overall and at least 60% in every cell. A pass only
licenses building and power-testing a search using the discriminator. A fail
retires this particular feature set. Neither result licenses scoring FAED.

## Development result

Passed. The full classifier ranked the planted order first in 30 of 30
evaluation fixtures, five of five in every width/board-mode cell. The
cheap-no-neighborhood and segmentation/transition/lag-only ablations also
scored 30/30. Neighborhood-only scored 6/30 and failed. This establishes that
the useful signal is cheap enough for a search objective; it does not establish
blind recovery.
