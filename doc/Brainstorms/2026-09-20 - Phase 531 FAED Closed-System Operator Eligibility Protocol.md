## Eligibility fields

Each candidate operator receives six Boolean fields:

1. `authenticated_source` — its input bytes are project-authenticated;
2. `faed_operand_binding` — independent evidence selects FAED as its operand;
3. `operation_selected` — the operation itself is selected rather than merely
   borrowed from cipher history;
4. `parameters_fixed` — every load-bearing alphabet, board, width, direction,
   boundary, and serialization parameter is fixed;
5. `consumer_fixed` — a downstream artifact is selected to consume the output;
6. `validator_fixed` — success is decidable without generic fluency or visual
   preference.

A row is executable only if all six fields are true and the exact cell is not
already covered. Failing one field cannot be repaired by an oracle hit.
