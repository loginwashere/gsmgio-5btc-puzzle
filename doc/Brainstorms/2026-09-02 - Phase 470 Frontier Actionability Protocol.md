# Phase 470 — Frontier Actionability Protocol

## Question

Phase 467 leaves four varying selectors and identifies the Architect relation
as having the greatest conditional dependency leverage. Which, if any, has a
genuinely new, currently executable internal test? In particular, is the Open
Gap Registry's proposed Architect transfer to solved/checksum boundaries new,
or does it duplicate Phase 456?

## Frozen inputs

- Phase 467's four-selector frontier and three closest live edges.
- Phase 456's exact transfer matrix over solved Phases 2, 3, and 3.2.
- The recorded topology, FAED-pair, and `thispassword` audits summarized in
  `GSMG_TOPOLOGY_AUDIT.md`, Phase 449, and Phase 455.
- The live `G-ARCH-001` registry action before this audit, which proposes
  testing authenticated solved/checksum boundaries for an edge/mirror
  prediction.

## Method

For each of the four Phase-467 selectors, record:

1. surviving alternatives;
2. conditional downstream selectors fixed if independently resolved;
3. completed internal evidence classes and their phase citations;
4. whether a proposed current action is an exact/semantic duplicate of a
   completed audit;
5. whether an already-held, genuinely unused input exists that satisfies the
   prior audit's eligibility conditions; and
6. the minimum new evidence class required for an informative test.

`conditional_leverage` and `executable_now` are reported separately. A
selector cannot be called actionable merely because resolving it would have
large consequences.

Lane A's FF67 calibration is also classified: a follow-up using the same
observed endpoint, another seed, another null, or a narrower companion set is
not blind. A blind test requires an input not used to formulate the event and
a prediction frozen before that input is examined.

## Decision rule

- `executable_now = true` only if a held input exists, has not already been
  used for the same test, and satisfies that test's frozen native-type,
  local-operation, and comparable-output gates.
- Otherwise classify the action as `duplicate`, `inapplicable_without_new_input`,
  or `selection_biased_reuse`.
- Correct stale registry wording when it queues an already-completed test.

## Prohibitions

No transforms, candidate generation, language scoring, password material,
hash candidates, decryptions, oracle calls, or rescans of exhausted corpora.
