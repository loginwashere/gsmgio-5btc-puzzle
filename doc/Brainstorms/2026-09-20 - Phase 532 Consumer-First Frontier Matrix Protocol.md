# Phase 532 — Consumer-First Frontier Matrix Protocol

Date: 2026-09-20

## Question

After Phase 531 found no closed-system FAED decoder eligible for execution,
does another tracked consumer define a complete, independently selected,
uncovered experiment?

## Frozen gates

A row is evidence-eligible only when all six fields are true before candidate
generation:

1. the consumer or target is authenticated;
2. the expected output schema is fixed;
3. a terminal validator is exact enough to promote by itself;
4. the input source is independently selected rather than analyst-chosen;
5. the serialization and transform are fixed; and
6. a finite scope remains genuinely uncovered.

Operational runnability is recorded separately. It is not a substitute for
gate 4: a finite historical coverage debt may be runnable without being a
puzzle-selected solving path.

The audit covers:

The matrix cites only existing project findings. It generates no passwords,
decrypts no object, scores no plaintext, and uses no GPU or network.

## Decision rule

- One or more six-of-six uncovered rows: nominate the highest-specificity row
  for a separately locked execution protocol.
- Zero six-of-six rows but an operationally runnable coverage debt exists:
  report it separately and do not call it evidence-selected.
- Zero rows and zero coverage debt: stop consumer-first execution until an
  existing closed-system artifact supplies a missing binding.

No result may be used to expand a row after inspection.
