## Phase 521 -- DBBI+FAED shared-board hypothesis, no calibrated consistency (2026-09-17)

**Question:** follow-up to Phase 520 (user-proposed): escape-pair choice
and board-key choice are logically separate steps of a straddling
checkerboard. What if each stream keeps its own already-established,
independently-best escape pair (DBBI `be`, FAED `gi`) for segmentation, and
only the board key (which letter sits in which of the 25 slots) is
hypothesized to be shared between them? Speaks directly to Phase
371/G-ESC-001's "each stream's own independently-best escape pair differs"
observation, previously read as evidence against a joint construction.

**Method:** `tools/gsmg/phase521_dbbi_faed_shared_board_hypothesis_audit.py`.
Statistic `cost_of_sharing = S_independent - S_shared` (always >= 0):
`S_independent` sums each stream's own independently-annealed best board
score; `S_shared` is the best score of ONE board annealed jointly to fit
both streams' own-pair-segmented codes at once (each scored on its own
contiguous quadgram windows, no cross-boundary artifact). Matched nulls
reuse Phase 459/460's Euler-traversal and endpoint-fixed-shuffle
generators, each null pair's own best escape pair re-selected the same
way as the real data. Reuses Phase 516's two-tier cheap/expensive
annealing-budget discipline: cheap budget (6,000x2) matched between the
real statistic and 500 null replicates per null; expensive budget
(60,000x30) as a real-data-only robustness diagnostic.

**Result:** real cost_normalized (cheap budget) = `0.1057`, below both
null medians (Euler `0.1830`, endpoint-shuffle `0.1945`) but not clearing
the pre-registered `p<=0.005` bar (`p=0.053892`/`p=0.023952`). Expensive-
budget diagnostic: cost_normalized nearly doubles to `0.1898` with 10x the
search budget -- more search improves each stream's independent optimum
faster than the constrained joint search, the pattern expected when there
is no real shared board, cautioning against reading the cheap-budget's
mild trend as signal. Decision: `no_calibrated_shared_board_consistency`
(Phase 460's controlled-vocabulary distinction for "positive-looking but
not robust," not a flat non-result like Phase 520's `p=0.43`).

**Disposition:** no calibrated evidence DBBI/FAED could share one board
while each keeps its own best escape pair. Corroboration_only; does not
select a board, reconcile G-ESC-001, or reopen/close G-YIN-001. Does not
rule out every joint-board idea, only this annealing-search-discoverable,
escape-pair-unconstrained version.

**Facts affected:** none.

**Supersedes/corrects:** none.

**Artifacts:** `tools/gsmg/phase521_dbbi_faed_shared_board_hypothesis_audit.py`,
`tools/gsmg/test_phase521_dbbi_faed_shared_board_hypothesis_audit.py`,
`tools/gsmg/phase521_result.json`.

**Reopen condition:** only on a new primary source/selector licensing a
shared-board construction, or a genuinely different non-annealing
board-recovery method with demonstrated power this search lacks -- not on
re-running this construction with more trials or a different schedule.
