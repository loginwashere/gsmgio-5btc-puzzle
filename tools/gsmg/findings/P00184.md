## Phase 184 -- Smith/Neo "equation" scene: four bounded phrases from the newly-surfaced repeated `"what do you want"` exchange, closed negative (2026-08-08)

Phase 183 item 3 found that Revolutions' climactic Smith/Neo rain-fight
monologue contains its own `"What do you want?" / "I want the same thing
you want"` call-and-response, independent of the Deus Ex Machina occurrence
Phase 182 already tested. This is a real, previously-uncatalogued
choice-adjacent scene (Neo's final choice in the film is to stop fighting
and let Smith assimilate him, moments after this exchange), so it earns its
own small bounded candidate family rather than silently folding into an
existing one.

`tools/gsmg/neo_smith_equation_audit.py`: four phrases declared before
testing, all short and directly quoted from the scene, sourced from
`the-matrix-revolutions-2003.en.srt` (SHA-256
`333e2a6ed3b3346e5db5d508ee749ea2c8ffbf47bf0510ca65b8e9863ecb7f0d`, scene
anchors and the 3x `"what do you want"` occurrence count verified before
the oracle runs):

- `"i want the same thing you want"`
- `"i want what you want"`

- `"nothing this weak is meant to survive"`

One incidental note the self-test pins down: the subtitle file itself
renders "I" as a lowercase "l" at *"...survive. -What do you want? -l want
what you want."* -- a subtitle-source typesetting/OCR artifact, not a
puzzle signal (the corrected reading is used for the candidates; the raw
literal reading is what the scene-anchor check matches against).

Same `material_family()` oracle as Phase 178/179/182: 4 candidates -> 48
materials (raw/upper/lower x letters-only variant x SHA-256/double-SHA-256
forms) -> 0 hits against SALPH/COSMIC/P32TRAILING. `test_recent_audits.py`
grew to 15 tests, all passing.

**Verdict:** closed negative. Same discipline as every other bounded
Neo-choice phrase family this project has tried -- no hit, no parameter
expansion. The trilogy-wide "words right before/at a Neo choice" avenue
now covers the door-choice scene (Phase 182), the Deus Ex Machina scene
(Phase 182), and this Smith/Neo equation scene (here); no further
