## Phase 541 — fresh-context agents round 2: derived facts and operation proposals, closed negative (2026-09-20)

**Question:** With the project's reconstructed closed-system objects added to the
dossier (prime-host parse and payloads, 25 events, 31-letter selection, Selection A
matrix, Bifid BTCSEED reading, size facts), can fresh agents propose operations, as
executable code with a named check, that produce an exact hit?

**Frozen inputs:** Dossier v2 (round-1 dossier plus six derived facts recomputed from
repository code, a list of already-tested families, and the operation interface); a data
file; six lens-specific agents on opus and sonnet (Fable unavailable). Protocol, prompts,
dossier, data, harness and dependencies hashed into a lock before the first agent ran.

**Method:** One round, one prompt per agent, at most 10 proposals and 150 candidates
each. Proposals ran exactly as written in an isolated process (import whitelist, static
checks, resource limits, empty environment, no file writes; not a security boundary
against adversarial code). Every returned string was scanned for key shapes against
eleven target hash160s; the union of candidates and first 1,000 outputs per proposal was
run through the GPU oracle (60-variant table, four tracked blobs, Bloom and known-target
detectors).

**Result:** 60 of 60 proposals passed the static check and ran. 12,633 unique bases
(12,191 not in round 1; 97% new against Phase 523 coverage). 6,979 key-shaped strings, 0
matches against the targets. Oracle: 386,685 forms, 0 strong, 0 structural, 0 known-target;
23 weak rows, all re-derived, none key-shaped; one Bloom hit a false positive after the API
check. The GPU tool skipped 40 `#`-prefixed noise bases and trimmed 21.

**Disposition:** rejected for this dossier, these lenses and one round; operation-type
generation, exact oracle and exact key-shape bar. Stop rule reached.

**Facts affected:** None.

**Supersedes/corrects:** None. Adds a set of operation outputs and candidates (97% new strings against earlier
coverage); mechanism novelty was not audited.

**Artifacts:** [audit](../../../doc/GSMG_PHASE541_FRESH_CONTEXT_AGENT_ROUND2.md),
`phase541_round2_build.py`, `phase541_round2_exec.py`, `test_phase541_round2_exec.py`,
`phase541_round2_prompts.json`, `phase541_round2_lock.json`, `phase541_round2_result.json`,
`phase541_round2_outputs/`, dated protocol.

**Reopen condition:** A changed dossier (a new artifact) or a new constraint on the
operation type chosen in advance. Not more agents or wider lenses on this dossier.
