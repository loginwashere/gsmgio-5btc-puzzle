## Phase 522 -- OpenSSL menu-gap round 2 (CAST5, RC4), closed negative (2026-09-18)

**Question:** round 1 (2026-07-26) rechecked the curated candidate corpus
against Blowfish/Camellia/SEED-CBC, historically plausible `openssl enc`
menu items no prior sweep had tried. CAST5, IDEA, and RC4 were also
classic menu items from the same era -- does the same corpus open any
tracked blob under these?

**Correction made before any real sweep:** the initial scoping claimed
IDEA needed no new dependency since `cryptography` exposes an `IDEA`
Python class. Verified directly this is wrong for this environment: the
installed OpenSSL 3.0.13 backend raises `UnsupportedAlgorithm` for IDEA
specifically (compiled out of this build, unlike Blowfish/CAST5/SEED which
remain reachable via the legacy provider) -- a class existing in the
Python API is not the same as the operation working. IDEA (and RC2, never
implemented by `cryptography` at all) excluded from the runnable variant
set; both would need pycryptodome, deferred as an explicit follow-up.

**Method:** `cb_common.py` gained `cast5` in `CIPHER_CLASSES`/
`CIPHER_BLOCK_SIZES` (zero other code change needed, since the existing
CBC/ECB oracle already generalizes over `cipher`), plus
`OPENSSL_MENU_GAP_ROUND2_CBC_CIPHER_VARIANTS` (CAST5-CBC, OpenSSL's single
128-bit key size, legacy+PBKDF2, 4 variants). RC4 needed a new dedicated
oracle (`aes_try_open_rc4_bytes`, key-only derivation, no block/IV, same
printable-z-score gate as the existing stream-mode oracle) plus
`OPENSSL_MENU_GAP_ROUND2_RC4_VARIANTS` at OpenSSL's three named RC4 key
sizes (40/64/128-bit, 12 variants). `extended_cipher_recheck.py` gained a
`--openssl-menu-gaps-round2` flag sweeping the same 648-candidate curated
corpus used by round 1. New module-level self-test round-trips a
known-positive synthetic vector for every variant plus an RC4
wrong-password negative control; 3 new `unittest` cases added; full
`test_cb_common.py` and `test_recent_audits.py` suites confirmed
unregressed.

**Result:** 17,037 CAST5-CBC attempts + 17,037 RC4 attempts = 34,074 total
across all 4 tracked blobs, **0 hits**.

**Disposition:** closed negative. No registered gap closes. The two new
variant lists are standing, reusable infrastructure for future candidate
corpora, matching round 1's status.

**Facts affected:** none.

**Supersedes/corrects:** none against prior phases; corrects this
investigation's own initial IDEA-availability scoping claim before any
real sweep ran against it.

**Artifacts:** `tools/gsmg/cb_common.py`,
`tools/gsmg/extended_cipher_recheck.py`, `tools/gsmg/test_cb_common.py`.

**Reopen condition:** a new curated candidate source, or a
pycryptodome-backed follow-up specifically scoped to IDEA/RC2 -- not a
re-run of this exact variant set against the same corpus.
