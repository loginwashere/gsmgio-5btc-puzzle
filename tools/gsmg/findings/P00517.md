## Phase 517 -- closed-system untried theory batch (Tier 1 + Tier 2), nine items all closed negative (2026-09-17)

**Question:** execute the nine deterministic, closed-universe theories
scoped in `doc/Brainstorms/2026-09-17 - Closed-System Untried Theory
Classes.md` (items 1a, 1b, 1c, 6, 4-primary, 10b, 8, 9, 7), each with a
pre-declared exact bar and stop rule, deferred from that ideation pass.

**Frozen inputs:** all nine candidate universes as declared in the source
brainstorm doc -- no widening after seeing any result. All nine are
deterministic/exhaustive over a small fixed universe, so none needed
execution-lock ceremony.

**Method:** `tools/gsmg/phase517_closed_system_untried_theory_batch.py`,
one function per item, reusing existing validated primitives
(`segment_raw`, `private_key_details`, `evaluate_materials`,
`raw_asset_byte_password_audit.run`, `p1a_sentinel_backfill.eligible_candidates`,
`aes_try_open_bytes`). A real implementation bug was caught during
development (not after publishing): a generic homomorphism-violation
helper keyed by the wrong side of a comparison for item 10b, silently
changing reported violation counts (79/70/485 vs. the correct 59/49/449)
without changing the negative disposition -- caught by cross-checking
against the original interactive run, fixed, and pinned as a regression
assertion in the script's `self_test()`.

**Result:**
- **1a** (DBBI as FAED's sum-list encoding, 112 cells, 5 length-matched):
  all 5 fail the exact homomorphism bar (41-57 violations, need 0) --
  including the noticed FAED-19x30-column/`a0i8` = 63-digit coincidence
  matching DBBI `{b,e}`'s token count, which does not survive the actual
  consistency test.
- **1b/1c** (FAED/DBBI as the last words before the Architect's "choice",
  29 pairs each): 746-853 and 82-122 bijection violations respectively.
- **6** (DBBI minus `a` as a 33-byte key, 8 candidates): compressed-pubkey
  reading fails structurally (leading byte `0x40`); 0 address hits on the
  other 3 readings.
- **4-primary** (FAED as base-9 binary with a file header, 16 candidates):
  0 header matches.
- **10b** (letter-class homomorphism, DBBI vs. `VALIDATION_ANSWER`/Phase-3.2
  plaintext; FAED vs. 34,264 windows of the full Architect scene): 59, 49,
  449 violations (need 0).
- **8** (Phase 381's 83-candidate manifest, previously `P32TRAILING`-only,
  now against SALPH/COSMIC/URLBLOB): 89,640 attempts, 0 hits.
- **9** ("zeroed out" characters at `{1,4,21}`/`{2,7,73}` on the three AES
  blobs): the literal base64-character-position reading is **structurally
  impossible** (0/18 variants parse as valid `Salted__` blobs -- those
  positions fall inside the header's own base64 encoding); the
  ciphertext-byte-offset reading: 1,008 attempts, 0 hits.
- **7** (Lo Shu magic square as a third digit convention, 8 symmetries,
  re-run against Phase 513's giant-decimal trick + header check): 11/16
  bodies valid, printable ratios in the established 34-53% noise range, 0
  header matches, 0 oracle hits.

**Disposition:** all nine items close negative under their pre-declared
bars. Item 9's negative is structural (the construction is impossible),
stronger than a search failure. None reopen or close any
`GSMG_OPEN_GAP_REGISTRY` entry. Not run (explicitly deferred): item 1b's
Phase-512 CSP pass at widths 15/19/30, item 2 (DBBI diagonals as FAED's
transposition key), item 5 (cipher-census bookkeeping), item 7's full
112-cell resweep under all 8 Lo Shu symmetries, item 4's secondary
725,760-candidate tier.

**Facts affected:** none.

**Supersedes/corrects:** none (the argument-order bug was caught and fixed
pre-publication).

**Artifacts:** `tools/gsmg/phase517_closed_system_untried_theory_batch.py`,
`tools/gsmg/test_phase517_closed_system_untried_theory_batch.py`.

**Reopen condition:** any item only reopens on a new creator source,
primary artifact, or authenticated selector specific to that item's own
construction, not on re-running the same construction again.
