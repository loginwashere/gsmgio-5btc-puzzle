## Phase 238 -- page-syntax house-style audit: mixed grammar, no directional selector (2026-08-11)

`tools/gsmg/page_syntax_house_style_audit.py` tests the proposed empirical
house-style route across all six authenticated instruction slots. It combines
the byte-exact page segmentation, the Phase-101 54-model grammar, the
presentation-layer audit, the independently structured `enter` control, and
Phase 236's default external macro model. No transform or oracle is run.

The role census is asymmetric:

- binary `enter` is the only locally fixed slot: an infix formatting marker
  between equal 64-character halves whose removal independently reconstructs
  the authenticated SALPH blob;
- binary `matrixsumlist` has a default external macro role
  (`574061 -> [23,16,7]`) but no fixed local DBBI/FAED direction;
- decimal `lastwordsbeforearchichoice` has a default external Architect role,
  demonstrating that immediate page neighbors need not be its operand;
- decimal `thispassword` remains a deictic label with three Phase-101 roles;
- the raw SHA prefix fixes the algorithm but not the referents of “our first
  hint” or “your last command”;
- the raw suffix fixes only `shabef -> sha256`; `anstoo` remains literal and
  unresolved.

Six proposed rules were falsified internally: uniform prefix, uniform postfix,
between-means-join, transport-fixes-role, nearest-neighbor operand, and a
complete SHA prefix/suffix bracket. **Zero of six survives.** In particular,
`enter` succeeds because of an independently valid consumer structure, not
merely because it is binary or between two fields.

Under working Model B, Phase 101's three-way local `matrixsumlist` axis can be
projected away, reducing 54 models to 18 residual password/SHA/tail tuples.
Nine are structurally total only by expanding `anstoo` to community-guessed
“answer too”; zero is source-strict. The projection is explicitly not
creator-authenticated.

**Verdict:** the page has mixed syntax, not a reusable directional house
style. It does not fix `matrixsumlist`, `thispassword`, the SHA operand, or
`anstoo`; it supplies no reopen evidence for selected-31 and authorizes no
transform or blob oracle. Full report:
