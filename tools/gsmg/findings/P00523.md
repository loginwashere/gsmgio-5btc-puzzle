## Phase 523 -- slot-grammar password product for SALPH: overlap audit, product essentially untested, execution pre-registered (2026-09-18)

**Question:** the 2026-09-18 closed-system reassessment reads the creator's
authenticated statements (no internet needed, hours after `yinyang`, "true
giveaway" last step, SHA-256 house style repeated on the page, SALPH's
80-byte ciphertext fitting a 64-hex private key) as fixing the shape of the
remaining work: a short visible string to hash, not a cipher to break. The
proposed lane enumerates the house-style password grammar over the macro
slots `yellowblueprimes -> matrixsumlist -> lastwordsbeforearchichoice ->
yinyang`, each filled by one authenticated checkpoint value or omitted,
joined in macro order. Before running it: how much of that product has
already been tried against SALPH?

**Frozen inputs:** 62 slot values (15/18/19/10), each tagged with its
ledger/phase source; two join conventions from Phase 341's solved-boundary
grammar (connected, single space); fixed macro order, no permutations; the
standard `answer_forms() x keystr_forms(newline_variants=True)` expansion;
18 coverage sources with SALPH in scope, each expanded the way its own
record says (648 corpus, 66,433 medium corpus, Phase 322/334 macro
permutations, V2 pool, and the script families of Phases 0.1, 4, 121, 179,
216, 232, 234, 265, 267, 372, 461). P32-only sweeps (270, 480, 481) and
raw-key tiers are excluded by name.

**Method:** `tools/gsmg/phase523_slot_grammar_overlap_audit.py --run`,
zero oracle calls (the unit test asserts no decrypt function is imported).
Materials are tagged `literal` (base and plain casings) versus `alpha`
(`answer_forms()` letters-only collapse) because `574061kit` collapsing to
an already-tested `kit` is not coverage of `574061kit`. A first
covered/not-covered classifier showed 8,434 "partial" bases that were
almost entirely this collapse; the tagged classifier replaced it before any
result was recorded.

**Result:** 133,696 deduplicated bases, 6,245,946 materials, 3,137,967
literal-family materials of which **726** were ever tried against SALPH.
Bases: 125,167 new, 8,480 alpha-only covered, 10 literal-partially
covered, 39 all covered (27 single values plus the 12 pure-label
concatenations Phases 79/322/334 swept). No multi-slot base built from
checkpoint values has had its literal form tried. 25 single-slot values
were never tried in any literal form, including `163`, the prime lists,
`23,16,7`/`46`, `401`/`400`/`73` and their joins, `FF67`/`255,103`, `kit`,
and the last 1-6 words before `choice`; `311027`, `04BEF3`, `1,4,21`,
`THEFLOWER`, the 31-char selection and `yingyang` were tried only in part.
Manifest SHA-256 `0f2b73fd...b6a52`; not-all-covered list (133,657 bases)
SHA-256 `ff5e80e9...92a18`, both under `_work/phase523/`.

**Disposition:** structural-only. Pre-registers the execution phase: the
not-all-covered list by digest, standard expansion, SALPH under
`KDF_VARIANTS` primary, standard detector plus prize-address derivation on
any hit, stop rule = zero hits closes the lane for these 62 values and two
conventions with no widening.

**Facts affected:** none.

**Supersedes/corrects:** none.

**Artifacts:** `tools/gsmg/phase523_slot_grammar_overlap_audit.py`,
`tools/gsmg/test_phase523_slot_grammar_overlap_audit.py`,
[doc/GSMG_PHASE523_SLOT_GRAMMAR_OVERLAP_AUDIT.md](../../../doc/GSMG_PHASE523_SLOT_GRAMMAR_OVERLAP_AUDIT.md).
